# 摘要收集器(summary-collector)

SillyTavern 扩展:逐楼识别 AI 回复中的**时间**与**摘要**,自动写入当前角色卡的**附加世界书**;每收集满 30 条自动做一次**大总结**(格式:`时间 - 事情`)。零侵入:只使用酒馆官方接口,不修改酒馆任何源码,不需要其他前置插件。

## 功能特性

- **标签可自定义**:摘要标签(默认 `dream_summary`,必填)、时间标签(默认留空 = 禁用)。一楼出现多个摘要块时只取第一个。
- **独立世界书,多挂载并存**:自动创建世界书(默认名 `<角色名>-摘要`)并追加挂到当前角色的**附加世界书**列表;不覆盖、不取消任何已有挂载。世界书内两个固定条目:
  - **摘要收集**(蓝灯常驻):每楼一条 `时间 - 摘要`,记录之间用 `<=>` 分隔;每次大总结后清空重来。
  - **摘要总结**(蓝灯常驻):大总结结果,每行一条 `时间 - 事情`;**只增不清**。
- **延后执行(默认 3 楼,可自定义)**:楼层记录先暂存,满 N 个 AI 楼层后才写入世界书 —— 这个窗口就是 swipe 宽限期,窗口内 swipe 会取最新内容;已写入的记录不回滚。
- **自动大总结**:收集满阈值(默认 30 条)后,再过 N 个 AI 楼层,用**当前连接的模型**后台静默归纳,不占用聊天楼层。失败自动保留现场、延后重试。
- **大总结独立 API 接入(v0.4.0)**:大总结请求可在两种模式间切换 —— **随主插件**(跟随酒馆当前激活的 API 连接,默认)/ **自定义API**(插件内自填 端点 + API 密钥 + 模型,一键拉取模型列表;请求与模型列表均经酒馆服务器代发,无浏览器跨域问题);失败时错误按 cause 链展开显示根因。
- **系统提示词来源(v1.5.0)**:大总结可选「不使用 / 自己写提示词 / 接酒馆预设 / 内置事件级 V5」。接预设时会先弹出**块挑选清单**(按酒馆真实块顺序列出,可勾选、可上移下移),保存后冻结为快照 —— 之后在酒馆里改预设不影响已保存结果,想更新点「重新挑选」。内置事件级 V5 是代码内固定文本、界面不可编辑,用于把逐楼记录稳定归纳成「时间 - 事情」时间线;内置词可自动按模型名选择中文版或英文版,也可手动锁定中文/English。
- **缺时间提醒**:时间标签已启用但某楼没提取到时间内容时,toast 提醒用户,该楼记录仅含摘要。

## 环境要求

- SillyTavern **1.14 及以上**(已在 1.14.0 与 1.19.0 实测通过;仅使用官方公开接口)
- 无其他依赖(不需要酒馆助手/TavernHelper)

## 安装

### 扩展面板安装

1. 酒馆顶部「扩展」面板 → **Install extension**(安装扩展);
2. 输入仓库地址:`https://github.com/liao05/summary-collector`;
3. 安装完成后刷新页面,在扩展面板找到「摘要收集器」。

## 快速开始

1. 打开任意角色卡的聊天(群聊暂不支持)。
2. 在扩展面板「摘要收集器」中确认摘要标签名与你的预设输出格式一致(默认 `dream_summary`)。
3. 正常聊天。AI 每楼回复中带 `<dream_summary>...</dream_summary>` 的内容会在 **3 个 AI 楼层后**被写入世界书。
4. 打开「世界书」面板 → 找到 `<角色名>-摘要` → 查看两个条目的实时内容;扩展面板底部有当前周期计数。
5. 收集满 30 条后,插件会自动大总结并 toast 通知;也可点「立即大总结」手动触发。

### 接酒馆预设做系统提示词

1. 面板「大总结提示词模板」→ 系统提示词来源选 **接酒馆预设**;
2. 在下拉里选一个酒馆 Chat Completion 预设 —— 首次选择会打开**块挑选清单**:
   - 清单按酒馆预设的**真实块顺序**排列(读 `prompt_order`,不是文件里的数组顺序),停用的块也会列出并标注「预设已停用」;
   - 默认勾选是启发式:插槽、主提示、故事/世界/人格类默认保留;思维链、文风、破限、`assistant`/`user` 起手等默认放弃;每行都能手动改;
   - 用 ↑↓ 调整顺序,插槽(蓝框行)就是本次总结内容的落位处;
3. 点 **保存并使用** → 冻结成快照,面板会显示「保留 N 个文本块 + M 个插槽(约 K 字)」;
4. 想换块或预设更新了内容 → 点 **重新挑选**,弹窗会回显上次保存的结果,不会被打回默认值。

### 内置事件级 V5(开箱即用、防误改)

系统提示词来源选 **内置事件级 V5** 即可,不需要手写、也不会被误改:

- 文本固定在代码里,界面只显示说明,不可编辑;
- 用途:把逐楼记录稳定归纳成「时间 - 事情」时间线,逐条覆盖、不合并、不跑题;
- 自动按模型名选择中文版或英文版,也可以手动锁定;
- 实测(DeepSeek V4.1 Flash、GLM-5.3):多楼素材逐条覆盖,无重复、无漏行。

**中英文自动切换(v1.5.0)**:内置词语言默认「自动」,按当前模型名判断——`gemini / gpt / claude / grok / llama / mistral` 等国外模型用英文版,`deepseek / glm / qwen / kimi / minimax / hy / step` 等国产模型用中文版;识别不到时默认中文。也可以在下拉里手动锁定「中文」或「English」。英文版第 3 条同样强制“中文输入→中文输出”,不会把中文记录总结成英文。面板会显示当前识别结果(如 `当前模型「global:gemini-3.8-flash」→ 英文提示词`)。

## 配置项说明

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 开 | 总开关 |
| 摘要标签 | `dream_summary` | 必填;AI 回复中 `<标签>...</标签>` 内为摘要 |
| 时间标签 | 空(禁用) | 可选;启用后记录为「时间 - 摘要」 |
| 记录分隔符 | `<=>` | 摘要收集条目内各楼记录之间的分隔行 |
| 总结阈值 | `30` | 收集满多少条触发大总结 |
| 延后楼数 | `3` | 收集写入与大总结延后的 AI 楼层数(用户楼层不计) |
| 世界书名 | 空(自动) | 留空自动命名 `<角色名>-摘要`;可指定已有书名复用 |
| 系统提示词来源 | 不使用 | 不使用 / 自己写提示词(文本作为 system 置顶)/ 接酒馆预设(先挑选块并冻结快照,再按顺序组装)/ 内置事件级 V5(代码内固定,不可编辑,跨模型) |
| 内置词语言 | 自动 | 内置事件级 V5 专用:`自动`(按模型名判断,国外模型用英文)/ `中文` / `English`;英文版仍强制中文输入→中文输出 |
| 大总结模板 | 内置 | `{{收集内容}}` 为占位符;可随时修改、恢复默认 |
| 大总结请求走 | 随主插件 | `随主插件`(跟随酒馆当前激活连接)/ `自定义API`(插件内自填端点与密钥) |
| 自定义API 端点 / 密钥 / 模型 | 空 | 自定义API 模式用;裸域名自动补 `/v1`,可勾"地址原样使用";"拉取模型"按钮经酒馆服务器拉取模型列表 |
| 地址原样使用 | 关 | 自定义API 模式:不自动补 `/v1`,按填写的地址原样请求 |
| 最大输出 tokens | 2048 | 自定义API 模式生效 |
| 请求超时秒数 | 120(0=不限时) | 大总结请求超时保护;超时后中止请求、释放重试锁 |

配置与大总结模板保存在酒馆数据目录的 `data/<用户>/user/files/summary-collector-config.json`(预设块挑选快照也在这个文件里);运行进度(计数/待写队列)保存在聊天文件的 metadata 里,随聊天切换自动跟随。

## 数据与清理

| 数据 | 位置 | 清理方式 |
| --- | --- | --- |
| 世界书及两个条目 | `data/<用户>/worlds/<角色名>-摘要.json` | 世界书面板删除,或手动编辑条目 |
| 运行进度 | 聊天文件的 `metadata.summary_collector` | 一般无需清理;换聊天自动各自独立 |
| 插件配置 / 预设快照 | `data/<用户>/user/files/summary-collector-config.json` | 删除该文件即可恢复默认 |
| 挂载关系 | 角色附加世界书列表(酒馆设置内) | 在角色卡/世界书面板手动取消挂载 |

卸载插件:删除 `extensions/summary-collector` 文件夹即可,无残留注入。

## 已知限制

- 群聊暂不支持(会 toast 提示并跳过)。
- 楼层一旦写入「摘要收集」,之后的 swipe 不会回滚该记录(延后窗口期就是宽限时间)。
- 标签名大小写敏感,需与预设输出完全一致。
- 大总结质量取决于当前连接的模型;失败时收集内容与计数保持原状,延后自动重试。
